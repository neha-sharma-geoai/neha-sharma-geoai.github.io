# Neha Sharma — GeoAI & Earth systems

A standalone, responsive portfolio site for Neha Sharma, designed around
geospatial research and the colors and textures of the natural world. Visitors
can switch between Vivid Earth, Ocean Signal, Canopy & Clay, and Lavender from
the palette selector in the navigation; their choice is saved in the browser.

## Journey maps

The interactive India and world maps use Natural Earth boundary data. The India
map uses the 1:10m boundary, and the world map uses the 1:110m boundary; each
map includes an attribution link and accessible popups for its journey points.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, JavaScript, and
local image assets; it does not require a build step or package installation.

## Publish with GitHub Pages

1. Push this folder to the root of a GitHub repository.
2. In the repository settings, open **Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The site is a static portfolio; update `index.html`, `styles.css`, and
`script.js` directly.
